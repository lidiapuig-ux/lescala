# L'escala

La memòria d'un edifici de Barcelona, el número 282, i de les persones que hi han viscut, de 1960 fins avui.

Web feta per Lidia Puig per a l'assignatura de vibe coding (Grau en Disseny, Facultat de Belles Arts, UB).

- `index.html`: la web sencera (HTML, CSS i JavaScript en un sol fitxer). El contingut de cada pis és a l'objecte `FASES`, al principi del script.
- `img/`: façanes, seccions i interiors dels pisos.

Per publicar-la: Settings → Pages → Deploy from a branch → `main` / `(root)`.
